# Aurumbrella — Luxury Editorial Rain Gear & Umbrellas

Aurumbrella is an editorial-grade, responsive digital experience for high-end rainwear and bespoke architectural umbrellas.

## Overview

- **Design Philosophy**: High contrast luxury editorial typography, rich neutral backgrounds, bespoke brand styling, and fluid responsive design across mobile (360px), tablet (768px), and desktop viewports.
- **Pages**:
  - `index.html` — Flagship Editorial Home Experience
  - `home_2.html` — Modern Boutique Architectural Collection
  - `products.html` — Curated Catalog with interactive filters & modal product views
  - `custom_branding.html` — Corporate and bespoke umbrella craftsmanship showcase
  - `warranty.html` — Lifetime warranty & craftsmanship guarantee
  - `contact.html` — Concierge directory, appointment scheduling & showroom locators

## Responsive Highlights
- Fluid adaptive navigation supporting mobile drawers (<768px) and desktop navigation bars (≥768px).
- High contrast accessibility adjustments on navigation, dropdowns, and interactive callouts.
- Responsive grid alignments across all breakpoints.
